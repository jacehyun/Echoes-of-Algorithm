# Echoes of Algorithm

**Echoes of Algorithm** is a quiz-based educational RPG developed in **Godot 4 using GDScript**. The game introduces players to **Machine Learning concepts** through interactive levels, progressive difficulty tiers, quizzes, roaming stages, and boss encounters.

## Overview

The project combines educational content with RPG-style gameplay to make learning Machine Learning concepts more engaging. Players progress through multiple stages, answer quiz questions, unlock higher difficulty levels, and complete boss encounters as they advance through the game.

## Features

- 36 Machine Learning quiz questions
- 3 difficulty tiers
- 12 sub-levels
- Progressive difficulty unlocking
- Roaming and level-based gameplay
- 4-round boss encounter
- Save system for player progress
- High-score / leaderboard system
- Multiple-choice educational questions
- Android APK support
- Retro-inspired 2D game presentation

## Technologies Used

- **Godot Engine 4**
- **GDScript**
- Godot Scene System (`.tscn`)
- Godot Resource System
- Android Export
- Git & GitHub

## Game Structure

The game progresses through three main difficulty levels:

### Beginner
Introduces fundamental Machine Learning concepts and basic gameplay mechanics.

### Intermediate
Provides more challenging questions and gameplay as the player progresses.

### Advanced
Contains more advanced Machine Learning topics and harder challenges.

After progressing through the levels, players encounter a multi-round boss battle that tests what they have learned throughout the game.

## Educational Goal

Echoes of Algorithm was designed to explore how game-based learning can be used to make technical topics such as Machine Learning more interactive and approachable.

Topics introduced in the game include concepts such as:

- Machine Learning fundamentals
- Supervised and unsupervised learning
- Datasets
- Features and labels
- Other introductory Machine Learning concepts
